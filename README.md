# PARMIN | پرمین

فروشگاه فارسی زیورآلات و پنل مدیریت نمایشی (فاز ۱).

## اجرای محلی

```powershell
npm.cmd install
npm.cmd run dev
```

- فروشگاه: http://localhost:5173/
- پنل مدیریت: **http://localhost:5173/admin**
- درباره ما: http://localhost:5173/about
- تماس با ما: http://localhost:5173/contact

> لینک پیش‌نمایش ادمین در نوار بالای فروشگاه هم وجود دارد. **ادمین فعلی بدون ورود است و صرفاً برای نمایش محلی ساخته شده؛ اطلاعات آن واقعی نیست. برای انتشار عمومی، احراز هویت و مجوزدهی ضروری‌اند.**

## مشخصات

React 19، TypeScript، Vite، Tailwind CSS، React Router، رابط فارسی RTL.
Vazirmatn برای رابط و Estedad برای تیترهای شاخص؛ سرمه‌ای، آبی‌طوسی، سفید.

**مرجع قطعی تصویری:** `Storefront_Home_APPROVED.png` و `Admin_Dashboard_APPROVED.png` که در مکالمه پروژه تأیید شدند. نسخه فعلی هنوز تطابق کامل ندارد، چون تصاویر اصلی محصولات و فایل شفاف لوگوی برند به مخزن GitHub منتقل نشده‌اند. از لوگو یا تصاویر جدید و جعلی استفاده نشود.

صفحه جداگانهٔ Design System طبق تصمیم جدید حذف شد؛ توکن‌ها و استایل مشترک در کد باقی مانده‌اند.

Backend با ASP.NET Core Web API / EF Core و SQL Server در فاز بعدی پیاده‌سازی می‌شود. پرداخت، انبارداری، خبرنامه و فرم تماس هنوز صرفاً نمایشی هستند.
