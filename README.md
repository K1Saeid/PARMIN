# PARMIN | پرمین

فروشگاه اینترنتی فارسی زیورآلات نقره و اکسسوری با پنل مدیریت.

> این مخزن اکنون شامل نسخهٔ اولیه رابط کاربری نمایشی است. پرداخت، انبار، ورود واقعی و اتصال پایگاه داده هنوز پیاده‌سازی نشده‌اند.

## تکنولوژی
- React + TypeScript + Vite
- Tailwind CSS 4
- React Router
- ASP.NET Core Web API + SQL Server (فاز آینده)

## اجرا
```bash
npm install
npm run dev
```

فونت UI: Vazirmatn؛ تیترهای شاخص: Estedad. طراحی RTL، رنگ‌های سرمه‌ای، آبی‌طوسی و سفید.
