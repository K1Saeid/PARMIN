# PARMIN immutable design rules
- Persian interface, `dir=rtl`, accessible labels.
- Vazirmatn for UI, Estedad for standout titles only.
- Approved blue-gray/white palette; no pink/gold redesign.
- Centered max-width 1200px storefront.
- RTL admin sidebar on right; exactly 12 stable menu items from `src/config.ts`.
- About and Contact links in footer, not primary navigation.
- No invented trust seals, verified contact details, or production payments.
- Reference images for approved store/admin are authoritative when available. Brand vector has not yet been provided.
- SQL Server + ASP.NET Core planned separately. Do not claim demo interfaces connect to a backend.
